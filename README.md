## 条款里几个容易忽略的限制

这些内容不在套餐表里，但会影响你怎么用。

**SLA 是 99.9%，赔付形式是账户抵扣。** 条款写的是网络与电力月度 99.9%，超出后每满一小时按该服务月费的 2% 计入账户余额，单月上限 50%，要在 30 天内开工单申请。每月最多 180 分钟的维护时间不计入。

**取消要提前 5 天。** 在续费日前 5 天通过客户区提交书面通知，取消后服务器数据立即删除，不留缓冲。想用完这个月就走人的，别忘了这一步。

**逾期有滞纳金。** 到期 3 天后加收 10%，到期 7 天后服务自动终止、数据永久删除。

**禁止事项列得很具体。** 加密货币挖矿、垃圾邮件、暴力破解、出站 DDoS、流量交换都在禁止之列；未经书面批准不允许嵌套虚拟化。拿它跑这些用途，账号会被停。

**没有 API、按小时计费、快照和自动备份。** 套餐页面上没有这些。备份要自己在机器里做，或者用外部方案。这一点对把它当生产环境的人很关键。

控制面板这块，官方现在叫 ctrl，能重启、重装系统、开 HTML5 VNC 控制台、装一键应用、设网络防火墙、重置 root 密码。早期中文测评里普遍写成 SolusVM，登录信息以开通邮件里那份为准，客户区的登录账号和控制面板账号不是同一个。
